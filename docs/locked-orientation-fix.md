# LOCKED 小幅俯仰后持续翻转修复

## 复现与原因

维护者更正后的现象为：内置 `mesh_demo` 在正视前方附近缓慢、小幅俯仰时，
光环沿法线突然翻转，静止后仍保持；不能以运动滞后或位置越过头部解释。
当前内置 offset 为 `[0,0.4,0]`，回归同时覆盖维护者提到的 `[0,0.3,0]`。

修复前的固定位置重放在每个俯仰角等待 240 帧充分收敛：`yaw=0,pitch=+0.1°`
时，头部局部前向仍约为 `(-0.001691,0.001745,-1)`，与正向相反。
慢速序列和 yaw/roll 用例同样失败。位置始终保持头部上方，排除了越过头部。

对于纯头部上方的定位点，定位方向始终与 `headUp` 平行，`headUp` 的球面切向
投影没有方向。旧实现退回世界上方向；头部俯仰穿过水平时，该世界参考投影变号，
所以最终目标姿态就反向，位置差收敛后也不会恢复。浮点四元数的投影残差与
`1e-9` 判断／通用 `normalize()` 的 `1e-4` 截断不一致还会引入零向量分支。

## 修复边界

- 退化或数值上接近头部上下极点时，用头部前向定义光环 `+Z`，不引用世界上方向。
- 非退化位置继续使用原来的球面上极点规则；保留定位、LOCKED 阻尼和角动量参数。
- 在该方向计算内以 `1e-6` 单位向量容差识别退化，并按已检查的向量长度直接归一化。
  绕法线有符号角改用 `atan2`，避免近对齐时 `acos` 丢失符号和精度。
- 世界、SYNC 首帧和刚性／物理预览共同使用该数学修复。无 JSON、协议、存档或 API 变化。
- `mesh_demo` 自带组旋转和每秒 15° 的视觉动画保持原样；根姿态回归检查动画之前的
  `BodyPose`／`AnchorFrame`，不把正常动画当作翻转。

## 验证

- 新增 `LockedPoleContinuityTest`，修复前最初 3 项全部失败；修复后通过。
- 定位高度 0.3/0.4、yaw 0/70/179/-100、小角度 -2°～+2°逐点充分静止。
- 60 FPS、1800 帧慢速俯仰，角动量开关分别验证，头部到光环距离始终大于 0.39。
- 覆盖上下方、零 offset、roll、多组 yaw 与接近极点的小 x/z 偏移；既有非极点
  球面方向测试及 SYNC 世界／预览回归保持通过。
- core 完整构建通过。逐平台联合构建和实际游戏证据在完成后记录于
  [2.5.1 适配验证表](orientation-2.5.1-verification.md)。

SYNC 的独立提交为 `4c43c38`，主线首次集成为 `0d81a89`；本修复在其后独立提交，
两项合并候选版本为 2.5.1。没有创建标签或发布。
