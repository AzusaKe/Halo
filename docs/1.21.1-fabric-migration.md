# Halo 1.21.1 Fabric 迁移记录

日期：2026-09-19  
目标分支：`1.21.1-fabric`  
功能基线：Halo `1.20.1-fabric` / HaloCore 2.4.0  
core 锁定提交：`224551ef3f76c36b60fd5c84caaf4fe8a71b5e3a`

## 范围与契约

本迁移保持 core 2.4.0 的定义、动画、物理、几何、所有权来源和 API v2 契约。Halo 仅替换 Minecraft 1.21.1 / Fabric 的输入、存储、通信、GUI、生命周期和 GPU 提交适配。旧世界的 `halo:world_data` NBT、Halo 网络消息的字节布局、定义 schema、资源 ID、配置及命令语义不变。

冻结的 `1.21.1-fabric-flash` 只用于核对 1.21.1 第三方符号和平台接口，没有合并其旧业务实现，也没有修改该分支。YSM 的已反编译符号按现有许可边界复用；渲染实现以当前 core 和 1.20.1 正式适配器为准。

## 渲染与优化

2.3.1/2.3.2 的共享 billboard/ring 几何、OBJ VBO、静态/动态 EBO、透明排序、单次提交材质缓存和资源代次回收均保留。1.21.1 受光路径有以下变化：

- 世界中未遮罩、`glowing:false` 的 billboard、ring 和 OBJ mesh 通过原生 `entity_solid` / `entity_translucent` RenderLayer 提交，由 Iris 选择实体 G-buffer 程序并管理基础、normal、specular 等纹理槽。
- 每次绘制继续以 core 输出的剔除、混合、深度写入和 lightmap 值为准；缓存 VBO 在原生实体材质路径覆盖当前 draw 的 light 属性，避免静态满亮值泄漏。
- 带 mask 的 mesh 保留隔离的 Iris 派生程序，因为原生 RenderLayer 不能表达 Halo 的灰度遮罩规则；私有源码改写仍只包装基础颜色采样，不替换 normal/specular 采样。
- GUI 玩家预览继续使用原生 GUI shader 和满亮光照，不进入 Iris 世界 G-buffer。

这建立了 1.21.1 的 LabPBR 数据通路，但不以“能编译”替代视觉结论。固定诊断资源包的 normal、smoothness/metalness、emission 截图对照尚待维护者签收；POM 是否作用于实体仍由光影包决定。

## 已执行验证

- Halo 平台单测：119 项，通过 119，失败/错误/跳过均为 0；包含官方 YSM 1.21.1 JAR 验签、旧网络字节、旧世界 NBT、EMF/YSM 坐标、Iris shader 改写、缓存与提交契约。
- HaloCore 独立检查：324 项，通过 324，失败/错误/跳过均为 0；公开预览提供者、旧 ClientPort、旧 mesh writer 和旧 render API 二进制调用方检查全部通过。
- Java 21 下执行 `clean build` 成功，最终分发检查确认 core 仅平铺打包一次、gitlink 与 provenance 一致、旧锚点 API v2 fixture 可链接运行；工作树提交后还需用 `-Prelease=true` 生成非 `.dev` 交付包。
- 独立专用服：加载 1,291 个配方和 1,399 个进度，注册 1.21 payload，`/halo list` 可执行，随后 `stop` 正常保存退出。
- 原版客户端：加载 12 个定义和 1 个实体锚点配置；GPU 准备 2 个 model VBO、4 个静态 EBO、864 个唯一顶点和 288 个三角形；进入单人世界后执行 `/halo show` 与 `/halo hide`，无崩溃并正常保存。
- Iris 组合客户端：进入同一世界，flat/lit-solid/lit-translucent 材质全部准备成功；显示 `ring_default` 和 `mesh_mask_demo`，执行资源重载并重建 generation 2，未出现 Halo shader/Mixin/OpenGL 错误。
- EMF/ETF/YSM 同装启动：Halo 的 YSM 与 EMF 版本/ABI 门禁均启用，EMF 捕获钩子确认注入；YSM 因上述官方 native 限制未进入真实模型渲染。

本地日志和外部测试包保存在 `F:/codex-cache/halo-1.21.1-migration-evidence/` 与 `F:/codex-cache/halo-1.21.1-compat/`，不进入仓库或发布 JAR。

## 人工签收清单

发布前仍应在普通 1.21.1 Fabric 实例完成以下目视项目，并把截图/日志补入本记录：

1. 原版、YSM 自定义模型和实际替换玩家头部的 EMF CEM 资源包分别验证世界锚点及生存/创造物品栏预览。
2. 使用固定 LabPBR 三图元诊断包，对照关闭/开启 `_n`、`_s` 后的 normal、smoothness/metalness 与 emission；单独记录 POM 是否由光影的 entity pass 支持。
3. 检查透明 mesh、遮罩阈值、`glowing:true` 覆盖层、资源重载、光影切换及 `compatibility` / `cached` 两种图元后端。
4. 如需声明 Forge/NeoForge，通过目标版本 Connector 另行执行服务端、双客户端、同步和光影检查；1.20.1 的历史结果不能复用。

在上述视觉项目完成前，README 不把 1.21.1 LabPBR 标记为完整验收。本次交付仅创建本地提交，不推送、不打标签、不创建 Release。
