# SYNC 头部局部偏移修复（开发阶段）

## 行为与范围

`sync_offset` 使用头部局部轴。设首次头部世界旋转为 `H0`、LOCKED 首帧基准为
`L0`、定义偏移为 `S`，先求 `C = inverse(H0) * L0`，再缓存 `R = S * C`。
后续世界朝向为 `H(t) * R`。原实现将 `S` 左乘到世界基准，令非单位偏移依赖
首次捕获的世界朝向；单位偏移仍保持原有行为。

有效定位偏移、朝向模式或 SYNC 偏移变化时，下一有效帧重建物理位置和姿态，
保留实例、佩戴关系和动画时钟。仅纹理／图层变化不重置世界和物理预览的运动。
刚性预览维持相同局部组合顺序；物理预览使用同一计算器并独立保存运动与时间。

本阶段不修改 LOCKED 极点、归一化或阻尼算法；SYNC 完成主线验证后，由维护者
更正现象描述，再重新诊断 LOCKED。两项修复完成后才向 10 条标准适配分支统一迁移。
没有 JSON schema、网络、存档或公开 API 变化。
