# 光环全局自发光 / v4

Fabric `2.5.0-ba.2+adapter.3`，实验分支 `Experimental/1.20.1-fabric`。
用户已认可 v3 整体效果，本轮只把 HALO 类型改为独立自发光，其他部件保持 v3。

继续通过完整 `_halo` 后缀识别，不写死角色名；已有模型部件后缀优先，随后使用纹理
后缀。带下划线的角色名、大小写语义匹配与普通材质回退不变。必须位于已启用 BA
的定义中（同目录伴生图启用协议不变），不强制将全部旧光环材质改成 BA。

光环节点的颜色替换、混色和原始发光强度保持不变，当前参考强度为 0.5。
运行时输出为 `nodeEmission * HALO_BA_HALO_EMISSION / max(exposure, 0.0001)`，
不再乘天空/方块光。曝光补偿使曝光后光环亮度稳定；雾、Bloom、遮挡及色调映射
仍由底包处理。固定光照参考模式保留原节点结果。

光影设置 → **Halo BA → 光环全局自发光**，默认倍率 1，可选
`0 / 0.25 / 0.5 / 1 / 2 / 4`。0 关闭发光输出；此选项统一影响 HALO 材质，
不影响身体、头发、眼口、眉毛、描边和普通 LabPBR。倍率保存在 Iris 光影设置中。
无需材质 JSON 或新增贴图；更新实验光影并重载即可应用本轮着色变化。

验证：core wrapper 与 Fabric 联合 build 成功，341 项 core 测试通过，平台
122 项通过、1 项外部 YSM 检查跳过。实际 GPU 编译/链接和 28 项数值用例通过，
覆盖天空/方块光变化、三种曝光、全局倍率 0/0.5/2 及眼口不受倍率影响。
补充资源解析行为用例验证任意角色 HALO 后缀及共享纹理部件，并避免误判 outline。
运行重载记录及是否完成视觉验收见交付 README；数值通过不替代最终视觉观察。

模型地面投影仍保留在实验路径，正式版候选见
[投影后续记录](ba-emission-and-shadow-followup.md)。本轮只推送实验分支，不合入主线、
不发布或移动任何标签。成品 `.local/ba/Halo-BA-experimental-v4.zip`。
