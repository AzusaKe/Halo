## Adapter contracts

Reset world capture before GameRenderer extraction, then collect one immutable core output at SubmitCustomGeometryEvent. AfterOpaqueFeatures consumes the early portion; a frame-graph completion hook consumes the late portion before Iris composites and camera teardown. Repeated stages and shadow passes cannot advance simulation or consume main-frame output. Preview drawing cannot reset world capture. Interrupted frames and disconnect invalidate pending output.

First person uses the camera quaternion. Deferred ModelFeatureRenderer preparation carries entity and base-model identity; cape/armor models cannot consume the body head slot in world or PIP. PIP scopes include deferred feature execution. Inventory mouse coordinates are initialized before background extraction.

GPU submission uses 26.2 binding layouts and reverse-Z. Native and Iris resident vertex streams are isolated, with lazy creation in the actual draw scope, layout validation, triangle-corner expansion for Iris, per-layout EBO revisions and completed-frame CPU fallback. Cached quad primitives preserve four-corner Iris attributes. Adjacent equal-state legacy batches merge without reordering. Reload, shader recreation and disconnect release cached resources. Profiling and OpenGL diagnostics are opt-in; GL diagnostics are disabled on Vulkan.

Core, JSON schema, configuration fields, API v2 and the nine payload layouts are unchanged. SavedData keeps `halo:world_data`, `Halos`/`UUID`/`Definition`, lenient UUID input and canonical integer-array output. Legacy import does not revive removed ownership when a current empty file exists. Bidirectional compatibility concerns Halo data, not downgrading a complete Minecraft world. No YSM integration is included on 26.2.

NeoForge .59 Vulkan startup requires `earlyWindowControl = false` in the isolated instance's `config/fml.toml`; the default early OpenGL window failed Vulkan surface creation before world load. After disabling it and restoring the Vulkan preference (Minecraft had fallen back to OpenGL), the ordinary loader entered the world with Vulkan 1.4.351 / NVIDIA 616.64. The user accepted world/first-person/preview, compatibility and cached modes, F3+T and clean exit (`evidence/native-vulkan-01`).
